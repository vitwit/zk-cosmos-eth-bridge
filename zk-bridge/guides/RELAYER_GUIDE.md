# Relayer Guide

## Overview

The relayer monitors the Cosmos chain for lock events and submits ZK proofs to Ethereum for minting.

## Configuration

All configuration is done via `.env` file in the project root.

### Required Environment Variables

```bash
# Cosmos Configuration
COSMOS_WS_URL=ws://localhost:26657/websocket
COSMOS_RPC_URL=http://localhost:26657
COSMOS_EVM_RPC_URL=http://localhost:8545

# Ethereum Configuration  
ETHEREUM_RPC_URL=http://localhost:8545

# Contract Addresses (update after deployment)
BRIDGE_SOURCE_ADDR=0x...
BRIDGE_DEST_ADDR=0x...

# Relayer Private Key
RELAYER_PRIV_KEY=your_private_key_here
```

## Running the Relayer

From project root:

```bash
# Ensure .env is configured
cp .env.example .env
nano .env

# Run relayer
go run cmd/relayer/main.go
```

## How It Works

1. **Monitors Cosmos**: Connects to Cosmos WebSocket and listens for transactions
2. **Fetches Lock Details**: Retrieves lock event data from EVM module
3. **Generates Proof**: Creates ZK-SNARK proof of transaction inclusion
4. **Submits to Ethereum**: Sends proof to BridgeDestination contract for minting

## Key Files

- `keys/proving.key` - Required for proof generation (generated by compiler)
- `keys/verifying.key` - Used for local verification
- `proof_event.json` - Generated proof data (temporary)

## Troubleshooting

**Error: proving.key not found**
- Run `go run cmd/compiler/main.go` first to generate keys

**Error: RELAYER_PRIV_KEY not set**
- Ensure `.env` file exists and contains `RELAYER_PRIV_KEY`

**Connection refused**
- Verify Cosmos and Ethereum nodes are running
- Check RPC URLs in `.env`
