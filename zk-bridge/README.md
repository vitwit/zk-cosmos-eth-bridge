# ZK-Bridge (Clean Architecture)

A Zero-Knowledge proof-based bridge for cross-chain token transfers between Cosmos and Ethereum.

## 🏗️ Project Structure

```
zk-bridge/
├── cmd/
│   ├── setup/          # Generates ZK keys and Verifier.sol (Keccak256 aligned)
│   ├── deployer/       # Deploys contracts (requires solc/hardhat)
│   └── relayer/        # Monitors and relays proofs
├── contracts/          # Solidity contracts
│   ├── BridgeSource.sol
│   ├── BridgeDestination.sol
│   └── Verifier.sol    # Generated by setup
├── pkg/
│   ├── circuits/       # GNARK circuit definitions
│   ├── prover/         # Proof generation logic (Keccak256 aligned)
│   └── rpc/            # RPC clients
├── keys/               # Generated proving/verifying keys
├── guides/             # Documentation
└── .env.example        # Configuration template
```

## 🚀 Quick Start

### 1. Setup Environment

```bash
# Copy environment template
cp .env.example .env

# Edit .env with your configuration
nano .env
```

### 2. Compile ZK Circuit & Setup

```bash
# Generates keys/ and contracts/Verifier.sol (using Gnark v0.14.0)
go run cmd/setup/main.go
```

### 3. Deploy Contracts

**Option A: Using Hardhat (Recommended)**
```bash
# Navigate to old project and deploy using existing setup
cd ../zk-bridge-final/contracts
npx hardhat run scripts/deploy.js --network localhost
```

**Option B: Using Go Deployer (Requires compiled bytecode)**
```bash
# Note: Deployer currently requires manual bytecode compilation
go run cmd/deployer/main.go
```

### 4. Run Relayer

```bash
# Ensure .env is configured with deployed contract addresses
go run cmd/relayer/main.go
```
